Horizon AI National Bank
AZURE AI · RETRIEVAL AUGMENTED · HUMAN IN THE LOOP

Banking documents, understood and verified.

Extracts fields from customer documents, validates them against approved bank policy, and answers policy questions with citations. Every verdict comes from a deterministic rule engine. The model explains and cites; it never decides.

View architecture

The rule engine decides

A comparison against a policy threshold is correct every time and traces to the clause it came from. A model is usually correct, and you cannot tell when it is not.

The model explains

Retrieval returns the governing section. The model writes the reasoning and the citation, and nothing that affects the outcome.

A human signs off

human_review_required is assigned in code after generation. No code path sets it false. The output schema has no approval value.
